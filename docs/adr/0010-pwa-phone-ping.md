# PWA phone ping; Email is the backup

Students and staff can install the app on a phone or laptop (standalone PWA). Chrome treats `http://localhost:3000` as a secure context, so install works in local development. A phone ping goes out when a Request is sent, when an Admin accepts it, when it is turned down, and when Arrival means the plastic is ready for Pickup. Print does not ping. Pings also live in the app under a bell, and the Student can allow or stop them. If the ping never arrives, turned-down and come-collect facts still go by Email (ADR 0009).
