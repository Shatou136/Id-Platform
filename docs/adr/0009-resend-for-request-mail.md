# Resend for turned down and come collect

“We said no” and “come pick up” are school mail, not printer events. Resend sends those two messages. Pickup mail goes out at Arrival, never at Print.

If `RESEND_API_KEY` is missing, the same copy is written to `data/mail-log.json` so the path can be tried locally. Sign-in no longer sends a confirm mail (ADR 0014).
